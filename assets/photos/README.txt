Tips
- Landscape (wider than tall) photos look best. About 1600 pixels wide is plenty.
- Keep each file under about 500 KB so pages load fast on phones.
- After adding a photo, open the page's .html file and update the alt="..." text
  next to the PHOTO comment so it describes the picture (for screen readers).
- Only use photos of clients with their written permission.
- To use a different name or add more photos, copy a <figure class="photo-slot"> line
  and change the file name.

Originals

- The website logo is site/assets/logo.svg: the moth badge without the text ring, which uses fonts
  visitors' computers don't have. icon-32.png and icon-180.png are the browser-tab and phone icons.
